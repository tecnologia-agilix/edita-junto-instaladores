# Edita Junto — instaladores

Aqui ficam **só os instaladores** do Edita Junto para Windows. O código do programa não está neste repositório.

## Instalar

1. Abra a [última versão](../../releases/latest).
2. Baixe o arquivo `Edita-Junto-<versão>-instalador.exe` e abra.
3. Siga o assistente. Não precisa de administrador.

## Atualizar

O Edita Junto procura versão nova sozinho (ao abrir e a cada 4 horas), baixa em segundo plano e avisa na tela inicial.
Ele nunca reinicia sem você pedir. Seus vídeos, clientes e conversas ficam na pasta de dados e não são tocados.

Os arquivos `latest.yml` e `.blockmap` de cada versão são usados pela atualização automática.
